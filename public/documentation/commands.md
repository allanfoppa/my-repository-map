# Linux Command Cheat Sheet

A quick reference for commonly used Linux commands.

## File and Directory Management

- `pwd` — Print the current working directory
- `ls` — List directory contents
- `cd` — Change directory
- `mkdir` — Create a new directory
- `rm` — Remove files or directories
- `cp` — Copy files and directories
- `mv` — Move or rename files and directories
- `touch` — Create an empty file or update the timestamp
- `cat` — Display the contents of a file
- `head` — Display the first few lines of a file
- `tail` — Display the last few lines of a file
- `find` — Search for files and directories
- `locate` — Find files by name
- `updatedb` — Update the file database for `locate`

## File Compression and Archiving

- `tar` — Create or extract tar archives
- `gzip` — Compress files
- `gunzip` — Decompress gzip files
- `zip` — Create zip archives
- `unzip` — Extract files from a zip archive

## Text Processing

- `grep` — Search for a pattern in files
- `awk` — Extract and manipulate text data
- `sed` — Stream editor for text manipulation
- `diff` — Compare files line by line
- `sort` — Sort lines of text files
- `cut` — Extract sections from lines of files
- `wc` — Count lines, words, and characters in a file
- `tee` — Redirect output to multiple files or processes

## System Information and Monitoring

- `top` — Display system resource usage and running processes
- `ps` — Display running processes
- `uptime` — Show system uptime and load averages
- `who` — Show logged-in users
- `date` — Display or set the system date and time
- `cal` — Display a calendar
- `df` — Show disk space usage
- `du` — Estimate file and directory space usage
- `free` — Show memory usage
- `uname` — Show system information
- `lsof` — List open files and processes
- `lscpu` — Show CPU architecture info
- `lshw` — Show detailed hardware configuration
- `lspci` — Show PCI device info
- `lsusb` — Show USB device info

## Networking

- `ifconfig` — Configure network interfaces
- `ping` — Send ICMP echo requests
- `nslookup` — Query DNS servers
- `netstat` — Show network connections and statistics
- `route` — Show or manipulate IP routing table
- `iptables` — IPv4 packet filtering and NAT
- `ssh` — Connect to a remote server via SSH
- `scp` — Copy files over SSH
- `ssh-keygen` — Generate SSH key pairs
- `curl` — Transfer data to/from a server
- `wget` — Download files from the web
- `iftop` — Show network bandwidth usage
- `nc` — Netcat utility for network connections

## User and Permission Management

- `sudo` — Run a command with administrative privileges
- `su` — Switch user account
- `chmod` — Change file/directory permissions
- `chown` — Change file/directory ownership
- `chgrp` — Change group ownership

## System Control

- `shutdown` — Shut down or reboot the system
- `reboot` — Reboot the system
- `halt` — Halt the system

## Scheduling and Background Tasks

- `crontab` — Schedule commands/scripts
- `nohup` — Run a command immune to hangups

## Shell Utilities

- `alias` — Create command aliases
- `source` — Execute commands from a file in the current shell
- `history` — Show command history
- `man` — Show manual pages for commands
- `which` — Show the location of a command

---

## Additional Utilities

- `rsync` — Synchronize files/directories between systems
- `sar` — Collect/report system activity information
