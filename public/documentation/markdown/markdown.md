# Markdown

## Blockquote

### NOTE

```markdown
> [!NOTE]
> This is a general note.
```

### WARNING

```markdown
> [!WARNING]
> Be careful when editing this file.
```

### TIP

```markdown
> [!TIP]
> Use version control to track your changes.
```

### IMPORTANT

```markdown
> [!IMPORTANT]
> Save your work frequently.
```

### CAUTION

```markdown
> [!CAUTION]
> For potential dangers.
```
